## Project Overview

Okasha Properties is a real estate website for:

- Company: Okasha Properties
- Location: Allahabad, Westridge III, Rawalpindi, Pakistan
- Contact email: info@okashaproperties.com

The site is a dependency-free static website built with plain Node.js, HTML strings, CSS, and JavaScript. There is no framework such as React, Next.js, Astro, or Vite.

The folder is not currently a Git repository. `git status` and `git diff` fail from this directory with `fatal: not a git repository`.

## Build And Dev Commands

Use these from the project root:

```powershell
npm run build
npm run dev
```

`npm run build` runs `node scripts/build.mjs` and writes the static site to `dist/`.

`npm run dev` runs `node scripts/dev.mjs`, builds once at startup, and serves `dist/`.

The dev server uses:

```text
http://localhost:3000/
```

If `npm run dev` fails with `EADDRINUSE`, a dev server is already running on port `3000`.

## Known Issues And Limitations

The project folder is not a Git repository. If the next session needs commit history, open the actual repo root or initialize Git only if the user asks.

`README.md` still says to open `http://localhost:4173/`, but `scripts/dev.mjs` currently serves `http://localhost:3000/`.

The site uses remote Pexels video URLs for testimonial previews. This depends on external network access in the visitor browser and should be replaced with local approved videos before launch.

Most property images are illustrative generated/stock-style assets, not real Okasha Properties images.

Projects and events are placeholders.

About page still has placeholder mission, vision, values, story, and company background.

Contact form uses `mailto:` only. There is no backend, database, spam protection, or email API.

Phone number and verified map link are not provided.

Hero image and real estate visuals are illustrative. They do not depict actual Okasha projects.

The homepage hero markup is inline in `src/pages.js`; if it grows, consider extracting it to a component, but do not refactor just for neatness unless needed.

CSS file is large and includes dense earlier CSS. Be careful when editing broad selectors like `.container`, `.section`, `.site-footer`, and media queries because they affect many areas.
